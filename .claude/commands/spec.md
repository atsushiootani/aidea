---
description: Start spec-driven development — write a structured specification before writing code
---

agent-skills:spec-driven-development スキルを呼び出します。

まずユーザーが何を作りたいのかを理解することから始めます。次の点について明確化質問をします。

1. 目的とターゲットユーザー
2. コア機能と受け入れ基準
3. 技術スタックの好みと制約
4. 既知の境界（常に行うこと、最初に確認すること、決して行わないこと）

その後、6つのコア領域（目的、コマンド、プロジェクト構造、コードスタイル、テスト戦略、境界）をカバーする構造化された仕様書を生成します。

仕様は docs/SPEC.md に保存し、続行前にユーザーに確認を取ります。
