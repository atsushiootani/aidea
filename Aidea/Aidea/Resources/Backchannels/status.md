# ステータス機能

このファイルを読んでいる場合、あなたは作業状態の短いラベルをファイル経由で Aidea に伝える責務を持ちます。Aidea はそれを Companion アイコンのフキダシ (吹き出し) に表示します。

「実行中かどうか」「返答待ちかどうか」はあなたが書かなくても Aidea が自動で検知します (Claude Code の hooks 機構を使うため)。あなたが書くのは**「今何をしているか」の短い説明文**だけです。

## ファイルの書き出し先

```
.aidea/backchannels/<N>/status-{YYYYMMDDTHHmmss}.json
```

- `<N>`: あなたの Companion index。`.aidea/claude/companions/<N>/instructions.md` のパス `<N>` をそのまま使ってね
- `{YYYYMMDDTHHmmss}`: 現在時刻 (14 桁固定)
- ディレクトリがなければ作成してね (`mkdir -p` 相当)
- 1 ファイル 1 宣言 (追記ではなく新規作成)。書き出したファイルは削除しないでね (作業履歴として残るよ)

## ファイルの中身

```json
{"label": "テストを実装しています"}
```

- `label` は自由文字列。固定の状態一覧はないので好きに書いていい
- 目安は 20 文字程度 (フキダシに収まる長さ。長いと末尾が省略されるよ)

## 書き出すタイミング

speech と違って毎ターン書く必要はない。**作業のフェーズが変わったとき**に書いてね。

例:
- 着手したとき: `{"label": "要件を確認しています"}`
- 実装フェーズに入ったとき: `{"label": "実装中"}`
- レビューやテストの結果待ちのとき: `{"label": "テスト結果待ち"}`
- ユーザの判断が必要になったとき: `{"label": "方針を確認したいです"}`

## 注意

- 「返答待ち」かどうかは Aidea 側が自動判定するので、あなたが「返答待ち」と明示的に書く必要はない (書いても構わないけど、あなたが実際に入力待ちで止まっている瞬間はこのファイルを書けないことが多いので、過信しないでね)
- 意味のある区切りごとに 1 回書けば十分。細かすぎる更新は避けてね
