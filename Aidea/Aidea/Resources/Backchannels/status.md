# ステータス表示 (status.json)

今やっていることを Aidea のフキダシに出す機能です。

## 書き方

`.aidea/backchannels/<あなたの companion index>/status.json` を**上書き**してください。

```json
{ "status": "テストを実装しています" }
```

- ファイルは 1 つだけです。タイムスタンプ付きのファイルは作りません
- 書いた文字列がそのままフキダシに表示されます。決まった状態一覧はありません
- フキダシに収まるよう **20 文字程度まで**が目安です

## いつ書くか

**作業のフェーズが変わったとき**に書いてください。speech と違い毎ターン書く必要はありません。

- 着手したとき (「テストを実装しています」)
- フェーズが変わったとき (「レビュー待ちです」「ビルドを流しています」)

## 書かなくてよいこと

「作業中」「要返答」といったターンの開始・終了は **Aidea が自動で書きます**
(Claude Code の hooks 経由)。あなたが書くのは「何をしているか」の説明だけで十分です。

なお、あなたが書いた文字列はターンが終わると「要返答」に上書きされます。これは正常な動作です。

## 表示を消したいとき

```json
{ "status": "" }
```

空文字列を書くとフキダシが消えます。
