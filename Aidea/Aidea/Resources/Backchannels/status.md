# ステータス表示 (status.json)

今の状態を Aidea のフキダシに出す機能です。ご主人がタブを切り替えなくても、
どのコンパニオンが何をしているかが一目で分かるようにするためのものです。

## 書き方

`.aidea/backchannels/<あなたの companion index>/status.json` を**上書き**してください。

```json
{ "status": "少女作業中" }
```

- ファイルは 1 つだけです。タイムスタンプ付きのファイルは作りません
- 書いた文字列がそのままフキダシに表示されます。決まった状態一覧はありません
- フキダシに収まるよう **20 文字程度まで**が目安です

## いつ書くか

**Aidea 側は誰も書きません。あなたが書かなければフキダシは更新されません。**

| タイミング | 例 |
|---|---|
| 作業に着手したとき | `{"status": "少女作業中"}` |
| 作業のフェーズが変わったとき | `{"status": "テスト実装中"}` `{"status": "レビュー待ち"}` `{"status": "ビルド中"}` |
| **ターンを終えるとき (必須)** | `{"status": "待機中"}` |

とくに**ターンの最後に「待機中」を書くこと**を忘れないでください。
書き忘れると、作業が終わっているのに「テスト実装中」のまま固まって見えます。

ご主人の返答が必要なとき (質問して止まるとき) は、待機中ではなく
`{"status": "要返答"}` のように、声をかけてほしいことが分かる文面にしてください。

## 文面の指示がある場合

**instructions.md やキャラ設定に文面の指示があるときは、このファイルの例よりそちらを優先してください。**

例えば instructions.md に「作業中の文面は "少女作業中" にして」「状態は絵文字を付けて書いて」
といった指示があれば、それに従うこと。状態の呼び名・粒度・書き出す頻度を独自に決める指示が
あればそれも優先されます。

このファイルが示すのはあくまで既定の例で、Companion ごとに上書きしてかまいません。

## 表示を消したいとき

```json
{ "status": "" }
```

空文字列を書くとフキダシが消えます。

## 注意

パーミッション確認などで**あなたのターンが止まっている間は、あなたはこのファイルを書けません**。
その間フキダシは直前に書いた文面のまま残ります。止まりそうな操作 (確認が必要なコマンド等) の
前には、あらかじめ `{"status": "確認待ち"}` のように書いておくと親切です。
