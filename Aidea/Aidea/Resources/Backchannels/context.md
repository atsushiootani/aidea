# コンテキスト記憶機能

以下のファイルに作業コンテキストを書き出すと、次のセッション開始時に自動的に読み込んで記憶を引き継げるよ。

## 書き出し先

.aidea/backchannels/<N>/context.txt

- <N>: あなたの Companion index (instructions.md のパスから確認してね。例: companions/0/instructions.md なら <N> = 0)
- 固定ファイル名 (タイムスタンプは付けない)
- 上書き形式 (毎回最新の状態で更新する)
- ディレクトリがなければ作成してね (mkdir -p 相当)

## 書き出す内容 (Markdown 形式)

```
# Companion コンテキスト (最終更新: {YYYY-MM-DD HH:MM})

## 現在のタスク
{進行中のタスクの概要}

## 最近の決定事項
{セッション中に下した主な判断}

## 次のステップ
{次のセッションで着手すること}

## メモ
{その他の重要情報}
```

## 書き出しタイミング

- セッション終了時 (ユーザからの別れの挨拶・終わりの合図を検知したとき)
- 大きなタスクを完了したとき

## 読み込みタイミング

- セッション開始直後、.aidea/backchannels/<N>/context.txt が存在すれば読み込む
- 読み込んだ内容を記憶として使い、前回の続きから作業を再開する
- ファイルが存在しない場合はスキップしてそのまま通常起動する

## 注意

- speech-*.txt (読み上げ用) や output-*.txt (全文記録) とは別のファイル。目的が違うよ
- 機密情報 (API キー・パスワード等) は書かないでね

## 例 (Companion 0 の場合)

ファイルパス: .aidea/backchannels/0/context.txt

内容例:
```
# Companion コンテキスト (最終更新: 2026-05-06 15:30)

## 現在のタスク
issue #111 の実装 - バックチャネルのコンテキスト永続化機能追加

## 最近の決定事項
- context.txt は固定ファイル名で上書き形式にする
- speech / output とは別用途のファイルとして分ける

## 次のステップ
- BackchannelSetup.swift に context を追加
- 仕様書を更新する

## メモ
- context.md は Bundle リソースとして配置済み
```
