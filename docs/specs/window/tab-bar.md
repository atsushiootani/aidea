# タブバー

PaneView のタブバー UI 振る舞い仕様。キーボードショートカットは [shortcuts.md](./shortcuts.md) に記載。

## タブの自動スクロール

タブが多くなりタブバーに収まらない場合でも、アクティブタブは常に表示領域内に自動スクロールされる。

- `pane.activeIndex` が変化するたびに、アクティブタブが見えるよう自動スクロールする
- スクロール先アンカー: `.center` でアクティブタブを viewport 中央に寄せる
- アニメーション付き (`easeInOut 0.2s`) でスクロールする
- タブの切り替え・追加・クローズいずれのケースでも同じルールが適用される
- スクロールインジケータは非表示

## タブのドラッグ&ドロップ

- `draggable(sessionID)` でタブを掴み、`TabSlotView`（タブ間の細い縦線）へドロップすることで同ペイン・異ペイン間でタブを移動できる
- ファイル URL をドロップすると新規 Preview タブが挿入される

## タブの追加

- `+` ボタン押下または **⌘T** でツール選択メニューを表示し、選択したツールを新規タブとして追加する
- 追加されたタブは即アクティブになり、自動スクロールでタブバーに表示される

## タブのクローズ

- **⌘W** またはタブ上の × ボタンでアクティブタブを閉じる
- 全タブが閉じられた場合、そのペイン自体をレイアウトツリーから削除する

### クローズ後のアクティブタブ選択 (issue #253)

- **アクティブタブを閉じた場合**: そのペイン内で**最も最近アクティブだったタブ** (MRU) をアクティブにする。
  MRU は `SessionRegistry.activeSessionHistory` (Active Session Switcher と同じ履歴、末尾が最新) を
  末尾側から走査し、ペイン内のタブに最初にヒットしたものを使う
- 履歴にペイン内のタブが 1 つも無い場合は従来どおり**隣接タブ** (同 index、末尾を閉じたら 1 つ前) にフォールバックする
- **アクティブでないタブを閉じた場合**: アクティブタブは変えない (削除による index ずれは補正する)
- ファイル削除に伴う Preview タブの自動クローズ (`closePreviewsForDeleted`) でも同じ選択規則を適用する
