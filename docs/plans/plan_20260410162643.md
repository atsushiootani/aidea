# 計画: Git ツール + GitDiff ツール (issue #26)
作成日: 2026-04-10

## 目的
Git の変更差分を閲覧・操作する Git ツール (シングルトン) と、
個別ファイルの diff を side-by-side 表示する GitDiff ツール (マルチインスタンス) を実装する。

## タスク一覧

- [ ] タスク1: Tool enum に .git / .gitDiff を追加
  - Tool.swift に case 追加、displayName / systemImageName 定義
  - PaneView.isAddable で .git をシングルトン制約
  - 依存: なし

- [ ] タスク2: GitService (git コマンド実行) を実装
  - Services/Git/GitService.swift: Process で git を実行するヘルパ
  - diff --name-status, diff <file>, diff main...HEAD 等
  - 依存: なし

- [ ] タスク3: GitChangedFile モデル + GitChangesLoader を実装
  - Models/Git/GitChangedFile.swift: status (M/A/D/R) + path + ツリーノード
  - Services/Git/GitChangesLoader.swift: --name-status パース → ツリー構造
  - 依存: タスク2

- [ ] タスク4: GitSessionState + GitSessionView を実装
  - Sessions/Git/GitSessionState.swift: モード (working/pr) + 変更ファイル一覧
  - Views/Sessions/Git/GitSessionView.swift: NSOutlineView + セグメントピッカー
  - ダブルクリック / Enter で GitDiff を別ペインに開く
  - 依存: タスク1, タスク3

- [ ] タスク5: GitDiffSessionState + GitDiffSessionView を実装
  - Sessions/Git/GitDiffSessionState.swift: ファイルパス + diff + モード
  - Views/Sessions/Git/GitDiffSessionView.swift: WKWebView + diff2html (CDN)
  - 依存: タスク1, タスク2

- [ ] タスク6: Discard 機能を実装
  - GitDiffSessionView にハンクごとの Discard ボタン
  - git apply --reverse でハンク単位の破棄
  - Working Changes モードのみ有効
  - 依存: タスク5

- [ ] タスク7: SessionRegistry に Git 関連メソッドを追加
  - openGitDiff(for:mode:) メソッド
  - createSession / view factory の .git / .gitDiff case 追加
  - 依存: タスク4, タスク5

- [ ] タスク8: 自動更新 (FSEvents)
  - .git 配下の変更検知で一覧を再取得 (デバウンス 500ms)
  - 依存: タスク4

- [ ] タスク9: 動作確認 + commit, push, PR
  - 依存: タスク8
