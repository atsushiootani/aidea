# 計画: Aidea MVP 初期実装
作成日: 2026-04-08

## 目的
SPEC.md で定義した MVP 5 機能 (ターミナル / WebView / Skills・Commands・MCPs ビュー /
3 ペインレイアウト / アプリ起動) を動く形で実装する。Xcode プロジェクト未作成の状態から、
ターミナルで Claude Code が起動でき、サイドバーに `~/.claude/` の内容が並ぶところまでを目指す。

## 技術的注意点
- **macOS 15 (Sequoia) 以上**を最低ターゲットとする (`if #available` で 15 未満分岐を書かない)
- **外部依存は SwiftTerm 1 個のみ**。Markdown / YAML / Keychain ラッパは Apple 標準で代用
- **SwiftTerm は SwiftPM で導入**。`Package.swift` ではなく Xcode の Package Dependencies から追加
- **WKWebView は `isInspectable = true`** を必ず有効化 (Safari Web Inspector 接続のため)
- **`~/.claude/` のパス解決**: ハードコードせず `FileManager.default.homeDirectoryForCurrentUser` を使う
- **frontmatter パース**: YAML 全体ではなく `---` 〜 `---` 間を正規表現で抽出し、`key: value` を逐行 split で十分
- **App Sandbox の扱い**: Sandbox を有効にすると `~/.claude/` が読めない / `Process` 起動が制限される。
  個人用なので **Sandbox は無効化**して進める (entitlements で `com.apple.security.app-sandbox = false`)
- **PTY 起動時のシェル環境**: `zsh -l` を起動して PATH を引き継ぐ。`SHELL` 環境変数も渡す
- **3 ペインレイアウト**: `NavigationSplitView` (macOS 13+) を採用。`HSplitView` よりモダン
- **frontmatter 抽出のエッジケース**: ファイル先頭が `---` で始まらない場合、空 frontmatter として扱う

## タスク一覧
- [ ] タスク1: Xcode プロジェクト作成
  - 受け入れ基準: `Aidea.xcodeproj` がプロジェクトルートに存在し、空の SwiftUI App テンプレートが
    macOS 15 ターゲットでビルド・起動できる。Sandbox は無効。
  - 依存: なし

- [ ] タスク2: ディレクトリ構造の雛形作成
  - 受け入れ基準: SPEC.md 4 章のディレクトリ (`App/`, `Views/Sidebar`, `Views/Main`, `Views/RightPanel`,
    `Services/`, `Models/`, `Utilities/`) が Xcode の Group として存在する
  - 依存: タスク1

- [ ] タスク3: SwiftTerm 依存追加と TerminalView 実装
  - 受け入れ基準: `TerminalView.swift` が SwiftTerm の `LocalProcessTerminalView` を
    `NSViewRepresentable` でラップし、起動すると `zsh -l` が動く。`claude` コマンドを実行できる。
  - 依存: タスク2

- [ ] タスク4: WebView 実装
  - 受け入れ基準: `WebView.swift` が `WKWebView` を `NSViewRepresentable` でラップし、
    `isInspectable = true` が有効。任意 URL を表示できる。デフォルトで `https://www.apple.com` を読み込む。
  - 依存: タスク2

- [ ] タスク5: FrontmatterParser 実装と単体テスト
  - 受け入れ基準: `Utilities/FrontmatterParser.swift` が `String` を入力に
    `[String: String]` (frontmatter) と `String` (本文) を返す。XCTest で 4 ケース以上 (正常 / 空 /
    frontmatter なし / 不正な区切り) パスする
  - 依存: タスク2

- [ ] タスク6: Skill / Command / McpServer モデルと Loader 実装
  - 受け入れ基準: `SkillsLoader` が `~/.claude/skills/*/SKILL.md` を走査して `[Skill]` を返す。
    `CommandsLoader` が `~/.claude/commands/*.md` を走査して `[Command]` を返す。
    `McpLoader` が `~/.claude.json` をパースして `[McpServer]` を返す。各 Loader の戻り値が
    実際の `~/.claude/` の内容と一致する
  - 依存: タスク5

- [ ] タスク7: SkillsListView / CommandsListView / McpListView 実装
  - 受け入れ基準: 各 View が対応する Loader を `@StateObject` で参照し、`List` で一覧表示する。
    選択行に description を表示する
  - 依存: タスク6

- [ ] タスク8: 3 ペインレイアウト (ContentView) 実装
  - 受け入れ基準: `NavigationSplitView` で左サイドバー (Skills/Commands/MCPs タブ切替) +
    中央 (TerminalView) + 右ペイン (WebView) を表示。各ペインがリサイズ可能
  - 依存: タスク3, タスク4, タスク7

- [ ] タスク9: アプリ起動と手動動作確認
  - 受け入れ基準: SPEC.md 6 章の手動確認チェックリスト 5 項目をすべて満たす
  - 依存: タスク8

- [ ] タスク10: README に起動手順を追記し初回ビルドコミット
  - 受け入れ基準: README.md にビルド方法 (Xcode で開く → Run) と Sandbox 無効化の注意が記載され、
    変更が `feat: implement MVP` としてコミットされる
  - 依存: タスク9
