# 計画: ファイラ機能と動的 projectRoot
作成日: 2026-04-08

## 目的
SPEC.md に追加した MVP 機能 #5〜#7 を実装する。
プロジェクトルートのハードコードを廃止して `WorkspaceState` に集約し、
NSOutlineView ベースのファイラ・FSEvents 監視・内蔵プレビューを追加して
4 ペインレイアウトに移行する。

## 技術的注意点
- **WorkspaceState は `@Observable` シングルトン的に運用** し、
  TerminalView / SkillsLoader / CommandsLoader / FileTreeView 全てが参照する
- **TerminalView は projectRoot 変更で再生成が必要** (PTY を再起動するため `id(projectRoot)` で View を作り直す)
- **NSOutlineView** は `NSViewControllerRepresentable` でラップする
  (`NSViewRepresentable` だと outline の sizing が崩れやすいため)
- **FSEventStream** は CoreServices の C API。コールバックは C 関数で書き、
  `Unmanaged.passRetained(self).toOpaque()` で self を渡す古典的パターン
- **ファイル選択 → プレビュー** の連携は `WorkspaceState.selectedFile` で行う
  (右ペインが selectedFile を監視して FilePreviewView に切り替える)
- **永続化**: projectRoot は `UserDefaults` の `aidea.projectRoot` キーに保存
- **セキュリティスコープ付きブックマーク** は不要 (App Sandbox 無効のため)
- **メニュー項目** は `AideaApp` の `commands` モディファイアで追加
- **巨大ファイルのプレビュー**: 1 MB 超のファイルは "プレビューしない" メッセージを出す
- **バイナリ判定**: 先頭 8KB に NUL バイトが含まれていればバイナリとみなしテキストプレビューしない

## タスク一覧

- [ ] タスク1: WorkspaceState 実装と既存コードの projectRoot 参照置き換え
  - 受け入れ基準: `Services/WorkspaceState.swift` を新規作成し、`projectRoot: URL?` と
    `selectedFile: URL?` を持つ `@Observable` クラスを定義。`AideaApp` で 1 つだけ生成して
    Environment 経由で配布。`TerminalView` `SkillsLoader` `CommandsLoader` のハードコードを
    `WorkspaceState.projectRoot` 参照に置き換え、起動時 `UserDefaults` から復元する。
    projectRoot が nil のときは TerminalView は空表示にする。
  - 依存: なし

- [ ] タスク2: 「ディレクトリを開く」メニュー実装
  - 受け入れ基準: `AideaApp` の `commands { CommandGroup(replacing: .newItem) { ... } }` で
    `File → ディレクトリを開く... (⌘O)` を追加。`NSOpenPanel` でディレクトリ選択を促し、
    選んだら `WorkspaceState.projectRoot` に書き込み、`UserDefaults` にも保存する。
  - 依存: タスク1

- [ ] タスク3: FileTreeNode モデルと FileTreeLoader 実装
  - 受け入れ基準: `Models/FileTreeNode.swift` に `id: URL` `name` `isDirectory`
    `children: [FileTreeNode]?` を定義 (children が nil = 未走査)。
    `Services/FileTreeLoader.swift` に `func load(_ url: URL) -> [FileTreeNode]` を実装し、
    指定ディレクトリ直下のみを返す (再帰しない遅延読み込み)。
    `func icon(for node: FileTreeNode) -> String` で SF Symbols 名を返す。
  - 依存: タスク1

- [ ] タスク4: FileWatcher (FSEventStream ラッパ) 実装
  - 受け入れ基準: `Services/FileWatcher.swift` に `start(path:onChange:)` `stop()` を実装。
    `FSEventStreamCreate` でストリーム作成、`kFSEventStreamCreateFlagFileEvents` 指定、
    コールバックで変更パスの集合を `onChange` に渡す。`projectRoot` が変わったら
    `stop → start` する。
  - 依存: タスク1

- [ ] タスク5: FileTreeView (NSOutlineView ラッパ) 実装
  - 受け入れ基準: `Views/Sidebar/FileTreeView.swift` を `NSViewControllerRepresentable` で実装。
    内部に `NSOutlineView` + `NSScrollView`、`NSOutlineViewDataSource` と `Delegate` を持つ。
    展開時に FileTreeLoader で子を読み込んで挿入。SF Symbols (`folder` / `doc.text` 等) を
    `NSImage(systemSymbolName:)` で表示。行選択で `WorkspaceState.selectedFile` に書き込む。
    `WorkspaceState.projectRoot` が変わったら全リロード。FileWatcher の通知でも該当ノードを
    再走査する。
  - 依存: タスク3, タスク4

- [ ] タスク6: FilePreviewView 実装
  - 受け入れ基準: `Views/RightPanel/FilePreviewView.swift` を新規作成。
    `WorkspaceState.selectedFile` を監視し、テキストファイルなら `TextEditor` (read-only) で
    表示、画像ファイル (png/jpg/gif/heic) なら `Image(nsImage:)` で表示、それ以外は
    "プレビュー非対応" を表示。1 MB 超は "ファイルが大きすぎます" を表示。
    バイナリ判定で NUL を含めばテキスト表示しない。
  - 依存: タスク1

- [ ] タスク7: 右ペインを Web/Preview 切替対応にする
  - 受け入れ基準: 既存 `WebView` の親に `RightPaneView` (新規) を作り、内部で
    `selectedFile == nil` のとき WebView、そうでなければ FilePreviewView を表示する。
    上部に「Web | Preview」のセグメント Picker を置いて手動切替も可能にする。
    selectedFile に切り替わると自動で Preview タブが選ばれる。
  - 依存: タスク6

- [ ] タスク8: ContentView を 4 ペイン構成に変更
  - 受け入れ基準: ルートを `HSplitView { VSplitView { FileTreeView; SidebarTabsView } TerminalView RightPaneView }` に書き換える。
    左カラム上下分割は `VSplitView` でリサイズ可。既存の Skills/Commands/MCPs の Picker は
    左下ペイン (`SidebarTabsView`) に移動。`projectRoot` が nil のときは中央に
    「ディレクトリを開いてください」のプレースホルダーを表示。
  - 依存: タスク2, タスク5, タスク7

- [ ] タスク9: 手動動作確認
  - 受け入れ基準:
    - メニュー「ディレクトリを開く」で aidea プロジェクトを開ける
    - ファイラに aidea のディレクトリツリーが表示される
    - フォルダ展開・折りたたみが NSOutlineView の流儀で動く
    - ターミナルが選んだディレクトリで開く
    - サイドバーの Skills/Commands に project 配下も表示される
    - ファイル選択で右ペインが Preview に切り替わり中身が出る
    - 外部で `touch newfile.txt` するとファイラに自動で出現する (FSEvents 動作)
    - アプリを再起動すると前回の projectRoot が復元される
  - 依存: タスク8
