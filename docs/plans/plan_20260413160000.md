# 計画: コンパニオンシステム (issue #38)
作成日: 2026-04-13

## 目的
ヘッダにコンパニオンアイコンを配置し、各コンパニオンが Claude セッションと 1-1 対応する。
コンパニオンごとに異なる初期プロンプトを設定でき、異なる役割やコンテキストで Claude を起動できる。

## 技術的注意点
- コンパニオン設定は `.aidea/companions.json` に永続化（ワークスペース単位）
- コンパニオン → Claude セッション の紐付けは CompanionState が管理
- ClaudeSessionState の autoStartClaude にコンパニオンの初期プロンプトを注入する
- 既存の SpeechState / BackchannelSetup との連携: 読み上げは全コンパニオン共通で `.aidea/terminals/` を使う
- アイコンはプリセット SF Symbols から選択（カスタム画像は将来）
- Aidea 起動時の自動起動フラグで、復元後に自動で Claude セッションを開く
