# 計画: Terminal と Claude ツールの分離 (issue #35)
作成日: 2026-04-13

## 目的
Terminal ツールは純粋な PTY シェルとして使い、Claude ツールは PTY + claude 自動起動 + Backchannel 指示送信を行う専用ツールにする。
現在 TerminalSessionState に混在している claude 自動起動ロジックを分離し、それぞれの責務を明確にする。

## 技術的注意点
- TerminalSessionState の PTY 起動ロジックは共通で使えるため、Claude 用も継承か委譲で再利用する
- Tool enum に `.claude` を追加し、SessionRegistry の makeState / view ルーティングも更新が必要
- PaneView のシングルトン制約（.filer, .git）に .claude を含めるかは要検討（複数 Claude セッション可にするか）
- `+` メニューから Terminal と Claude が別々に選べるようになる

## タスク一覧
- [ ] タスク1: Tool enum に `.claude` を追加

  - 依存: なし
- [ ] タスク2: TerminalSessionState から claude 自動起動ロジックを削除
  - 受け入れ基準: TerminalSessionState は PTY を起動するだけで、claude の send() は行わない
  - 依存: タスク1
