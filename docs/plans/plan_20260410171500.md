# 計画: 読み上げ機能 (issue #4)
作成日: 2026-04-10

## 目的
複数のターミナル出力をClaude APIで要約し、VOICEVOXで読み上げる機能を実装する。
ヘッダエリアに女の子アイコンと声アイコンを配置し、ON/OFFトグルで制御する。

## 技術的注意点
- VOICEVOX エンジンが `http://localhost:50021` で起動している必要がある（未起動時のフォールバック）
- 音声合成は `POST /audio_query` → `POST /synthesis` の 2 ステップ API (speaker: 20)
- SwiftTerm の `dataReceived(slice:)` をオーバーライドしてターミナル出力を傍受できる
- コマンド完了検知はプロンプトパターン (`$ ` や `% `) のマッチングで実現
- `terminal.getBufferAsData()` でバッファ全体のテキスト取得が可能
- 複数ターミナルから同時に読み上げリクエストが来る場合はキューで順番に処理
- Claude API (Haiku) は既に翻訳で使用中 — 同じパターンで要約にも使える
- 要約は100文字以内に制限

## アーキテクチャ

```
ターミナル出力検知 (PersistentTerminalView.dataReceived → プロンプト検知)
    ↓
コマンド出力テキスト抽出 (Terminal.getBufferAsData)
    ↓
Claude API で要約 (Haiku, 100文字以内)
    ↓
SpeechQueue にエンキュー
    ↓
VOICEVOX API (audio_query → synthesis → WAV)
    ↓
AVAudioPlayer で再生
```

## タスク一覧
- [ ] タスク1: VoicevoxService の作成
  - 受け入れ基準: `http://localhost:50021` への audio_query / synthesis 呼び出しで WAV データを取得できる
  - 依存: なし
- [ ] タスク2: SpeechQueue の作成
  - 受け入れ基準: テキストをキューに追加し、VOICEVOX → AVAudioPlayer で順番に再生できる。再生中に新しいテキストが来たらキューに積む
  - 依存: タスク1
- [ ] タスク3: OutputSummarizer の作成
  - 受け入れ基準: ターミナル出力テキストを Claude API (Haiku) で100文字以内に要約できる
  - 依存: なし
- [ ] タスク4: PersistentTerminalView にコマンド完了検知を追加
  - 受け入れ基準: dataReceived をオーバーライドし、プロンプトパターンでコマンド完了を検知。完了時に直近の出力テキストをコールバックで通知
  - 依存: なし
- [ ] タスク5: SpeechState の作成
  - 受け入れ基準: 読み上げ ON/OFF 状態を @Observable で管理。ON 時にターミナル完了通知 → 要約 → 読み上げの一連のフローが動く
  - 依存: タスク2, タスク3, タスク4
- [ ] タスク6: AppHeaderView の作成
  - 受け入れ基準: 女の子アイコンとメガホンアイコンが表示され、タップで ON/OFF トグル（デフォルト ON）
  - 依存: タスク5
- [ ] タスク7: ContentView にヘッダを統合
  - 受け入れ基準: ヘッダが SplitLayoutView の上に表示され、全ターミナルの読み上げが動作する
  - 依存: タスク6
- [ ] タスク8: エラーハンドリング
  - 受け入れ基準: VOICEVOX 未起動時 / Claude API エラー時にクラッシュせず、ヘッダにステータスを表示
  - 依存: タスク7
