# 計画: 自動翻訳機能 (issue #27)
作成日: 2026-04-10

## 目的
英語のドキュメントを Claude API で日本語翻訳し、`.aidea/ja/` にキャッシュする。
Preview ツールで英語ドキュメントを開いたとき、フローティングの「日本語」ボタンで
翻訳版を隣のタブに開ける。

## PR 分割

### PR 1: `.aidea/` プロジェクトディレクトリの自動作成
**スコープ**: `.aidea/` ディレクトリと `.gitignore` への追記のみ。翻訳機能は含まない。

### PR 2: 翻訳機能本体
**スコープ**: 言語判定 + Claude API 翻訳 + キャッシュ管理 + UI

---

## 技術的注意点
- **Claude API**: `https://api.anthropic.com/v1/messages` を `URLSession` で直接叩く。
  API キーは `UserDefaults` に保存 (MVP)。将来 Keychain に移行。
- **言語判定**: `NaturalLanguage` framework の `NLLanguageRecognizer` で先頭 1000 文字を解析。
  `.dominantLanguage == .english` ならボタン表示
- **キャッシュ構造**: `<projectRoot>/.aidea/ja/<元ファイルの相対パス>` にミラー配置。
  例: `docs/README.md` → `.aidea/ja/docs/README.md`
- **鮮度判定**: キャッシュファイルの mtime と元ファイルの mtime を比較。
  元ファイルの方が新しければ再翻訳
- **翻訳対象**: テキストファイル全般 (Markdown に限らない)。
  バイナリ判定で NUL を含むファイルは対象外
- **翻訳表示**: 隣の Preview タブとして `openPreviewAsSibling` で開く。
  タブ名は `<ファイル名> (日本語)` 形式
- **翻訳 API エラー**: NSAlert で表示。ネットワーク不通やキー未設定もここでハンドリング

## PR 2: 翻訳機能本体

### タスク一覧

- [ ] タスク2-1: Claude API クライアント実装
  - 受け入れ基準:
    - `Services/Translation/ClaudeTranslator.swift` に
      `func translate(text: String) async throws -> String` を実装
    - `URLSession` で `api.anthropic.com/v1/messages` を叩く
    - モデル: `claude-sonnet-4-6` (翻訳には十分、コスト効率良い)
    - システムプロンプト: 「以下の英語テキストを日本語に翻訳してください。
      Markdown の構造 (見出し、リスト、コードブロック等) はそのまま維持してください。」
    - API キーは `UserDefaults.standard.string(forKey: "aidea.anthropicApiKey")` から取得
    - キー未設定時はエラーを throw
  - 依存: なし

- [ ] タスク2-2: API キー設定 UI
  - 受け入れ基準:
    - メニュー「Aidea → 設定...」に API キー入力欄を追加
    - `NSAlert` + `NSSecureTextField` ベースのシンプルなダイアログ
    - 入力したキーを UserDefaults に保存
    - キー未設定で翻訳ボタンを押した場合は設定ダイアログを先に開く
  - 依存: なし

- [ ] タスク2-3: 言語判定サービス実装
  - 受け入れ基準:
    - `Services/Translation/LanguageDetector.swift` に
      `static func isEnglish(_ text: String) -> Bool` を実装
    - `NLLanguageRecognizer` で先頭 1000 文字を解析
    - `.dominantLanguage == .english` なら true
  - 依存: なし

- [ ] タスク2-4: 翻訳キャッシュマネージャ実装
  - 受け入れ基準:
    - `Services/Translation/TranslationCache.swift` に
      `cachedURL(for:projectRoot:)` `isFresh(original:cached:)` `save(text:to:)` を実装
    - キャッシュパス: `<projectRoot>/.aidea/ja/<相対パス>`
    - 鮮度判定: キャッシュの mtime >= 元ファイルの mtime なら fresh
    - 中間ディレクトリは自動作成
  - 依存: なし

- [ ] タスク2-5: 翻訳ボタン UI (Preview ツール)
  - 受け入れ基準:
    - MarkdownContainer / PreviewSessionView の view モードで、
      表示中テキストが英語判定されたら右上に「日本語」ボタンをフローティング表示
    - ボタンは Edit ボタンの下に配置
    - ボタンタップ → 翻訳フロー (タスク2-6) を開始
    - 翻訳中はボタンが「翻訳中...」に変わりインジケータ表示
  - 依存: タスク2-3

- [ ] タスク2-6: 翻訳フロー統合
  - 受け入れ基準:
    - ボタンタップ → キャッシュ確認 → fresh ならキャッシュ読み込み → 表示
    - stale or 未キャッシュ → Claude API で翻訳 → キャッシュ保存 → 表示
    - 表示: `registry.openPreviewAsSibling(for: cachedURL, title: "<ファイル名> (日本語)")`
      で隣タブに開く
    - API キー未設定 → 設定ダイアログ → 設定後に再試行
    - エラー → NSAlert 表示
  - 依存: タスク2-1, タスク2-2, タスク2-4, タスク2-5

- [ ] タスク2-7: テキストファイル全般への対応
  - 受け入れ基準:
    - Markdown 以外のテキストファイル (plain text) でも英語なら翻訳ボタン表示
    - PreviewSessionView の `.text` ケースでも言語判定 + ボタン表示
    - 翻訳結果もテキストとしてキャッシュ・表示
  - 依存: タスク2-6

- [ ] タスク2-8: specs/tools/preview.md に翻訳機能を追記
  - 受け入れ基準:
    - 翻訳ボタンの表示条件、翻訳フロー、キャッシュ構造を記載
    - 受け入れ基準を追加
  - 依存: タスク2-7

- [ ] タスク2-9: commit, push, PR 作成
  - 依存: タスク2-8
