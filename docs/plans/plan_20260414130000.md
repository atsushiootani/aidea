# 計画: Frontchannel レコメンドモード (issue #41)
作成日: 2026-04-14

## 目的
どのビューからでも Cmd+Enter でコンパニオンにプロンプトを送信できるレコメンドモードを実装する。
コンパニオンアイコンの下に吹き出しでプロンプト候補を表示し、選択して Claude セッションに送信する。

## 技術的注意点
- Cmd+Enter はどのビューからでも効く必要がある → NSEvent ローカルモニター or SwiftUI CommandMenu
- レコメンドモード中は他のキー操作をブロックする必要がある
- 吹き出しの位置をコンパニオンアイコンに合わせて動的に配置する
- ClaudeSessionState.terminalView.send(txt:) でプロンプトを送信
- コンパニオン未起動時は自動起動してから送信（遅延が必要）

## タスク一覧
- [ ] タスク1: RecommendProvider プロトコルの作成
  - 受け入れ基準: SessionState に recommendedPrompts() -> [String] を追加。GitSessionState が ["コミットして", "プッシュして", "PRを作って"] を返す
  - 依存: なし
- [ ] タスク2: RecommendState の作成
  - 受け入れ基準: isActive, selectedCompanionIndex, selectedPromptIndex, prompts を @Observable で管理
  - 依存: タスク1
- [ ] タスク3: RecommendBubbleView の作成
  - 受け入れ基準: コンパニオンアイコンの下に吹き出しを表示。プロンプトを縦に並べ、選択中をハイライト
  - 依存: タスク2
- [ ] タスク4: CompanionView にレコメンドモード表示を統合
  - 受け入れ基準: RecommendState.isActive 時に選択中コンパニオンの下に吹き出しを表示
  - 依存: タスク3
- [ ] タスク5: Cmd+Enter でレコメンドモード起動
  - 受け入れ基準: どのビューからでも Cmd+Enter でレコメンドモードに入る。現在アクティブなビューの recommendedPrompts が表示される
  - 依存: タスク4
- [ ] タスク6: 上下左右キー・Enter・Esc のキー操作
  - 受け入れ基準: 上下でプロンプト選択、左右でコンパニオン切替（吹き出し移動）、Enter で送信、Esc でキャンセル
  - 依存: タスク5
- [ ] タスク7: Frontchannel 送信処理
  - 受け入れ基準: 選択したプロンプトを対象コンパニオンの Claude セッションに send() する。未起動なら自動起動。送信後にアクティブタブにする
  - 依存: タスク6
- [ ] タスク8: ビルド確認
  - 受け入れ基準: BUILD SUCCEEDED
  - 依存: タスク7
